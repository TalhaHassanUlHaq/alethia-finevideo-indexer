# AI chat history

The assignment requires complete, unedited histories from every AI tool used.
This directory contains the project task handoffs and Gemini completion
records. Before publishing, also add the user-exported Codex/ChatGPT and
Gemini/Antigravity share links to `links.txt`, or copy the native conversation
exports here as directed by each tool.

Replace only passwords and API tokens with `[REMOVED]`; do not shorten or edit
the substantive history.
